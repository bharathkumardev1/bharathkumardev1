I'm Bharath Mandha, an AI/ML engineer. I work on retrieval and agent systems over financial documents, and before that built readmission risk models and demand forecasts.

The three repos below use public data, with code, evaluation and results committed. What CI checks differs by repo, so each entry says which.

- [finance-rag-eval](https://github.com/bharathkumardev1/finance-rag-eval): retrieval over SEC filings, scored page by page on FinanceBench. Reading the company and period from the question and sending statement questions to statement pages takes held-out Hit@10 from 0.14 to 0.71; leaving the company name out of the query adds 0.04, which is within noise. A MiniLM hybrid led on dev and tied BM25 on test at about five times the latency, so the service runs BM25. CI doesn't rerun the full evaluation; it runs a regression gate on the dev questions' filings and fails if dev Hit@10 falls more than one question below the recorded 38 of 50.
- [readmission-capacity](https://github.com/bharathkumardev1/readmission-capacity): which discharged patients a care team should call when it can call one in ten. On 101,766 public encounters split by patient, a LightGBM call list holds 25.0% of 30-day readmissions, against 20.5% for calling whoever had the most prior inpatient stays. The README spells out who it misses. CI downloads the data, retrains, and fails if the headline metrics move beyond a small tolerance.
- [Agentic-Research-Assistant](https://github.com/bharathkumardev1/Agentic-Research-Assistant): cited answers about research papers from a LangGraph loop that reviews its own answer. On QASPER the loop ties a single pass that stops at the first search's top 5 passages and loses to a single pass over 10 or 15 (test, judged correct: 58.7% against 68.0%; the loop averages 5.6 passages), so a wider first search is the better use of the budget. CI replays the recorded model calls with no API key and fails if any answer, citation or score comes out different. I graded 40 answers myself to check the judge, which agreed on 87.5%.

The first two have demos that run in the browser at [bharathkumardev1.github.io](https://bharathkumardev1.github.io), next to my résumé.
