I'm Bharath Mandha, an AI engineer in Dallas. I work on retrieval and agent systems over financial documents at Goldman Sachs, and before that built readmission risk models at Cigna Healthcare and demand forecasts for a retail client at Deloitte.

The repos below use public data, with code, evaluation and results committed. What CI checks differs by repo, so each entry says which.

- [wiki-retrieval](https://github.com/bharathkumardev1/wiki-retrieval): retrieval over the 2.68M-passage BEIR Natural Questions corpus. A LoRA-tuned MiniLM reaches nDCG@10 0.402 on the full corpus, 0.014 above the untuned encoder (paired p 0.0001) and 0.112 above my own BM25 (0.290). On a 104K-passage dev slice an INT8 ONNX cross-encoder adds 0.0941 nDCG@10 at 794 ms p50 on 2 vCPU; the hybrid and reranker were not run on the full corpus. CI runs on Python 3.11 and 3.13, Go, the image build and Terraform. [Demo video](https://www.youtube.com/watch?v=5vtW4iaUe3A).
- [tlc-demand](https://github.com/bharathkumardev1/tlc-demand): a LightGBM Poisson forecast of 15-minute NYC taxi pickups, 45 minutes past the last observed data. WAPE 0.2415 against 0.3104 for the best simple baseline, and it loses in the two quietest zone quartiles. A Java Spring Boot gateway with a circuit breaker serves a static fallback. [Demo video](https://youtu.be/Hd28gbz9jy0).
- [finance-rag-eval](https://github.com/bharathkumardev1/finance-rag-eval): retrieval over SEC filings, scored page by page on FinanceBench. Reading the company and period from the question and sending statement questions to statement pages takes held-out Hit@10 from 0.14 to 0.71; leaving the company name out of the query adds 0.04, which is within noise. A MiniLM hybrid led on dev and tied BM25 on test at about five times the latency, so the service runs BM25. CI doesn't rerun the full evaluation; it runs a regression gate on the dev questions' filings and fails if dev Hit@10 falls more than one question below the recorded 38 of 50.
- [readmission-capacity](https://github.com/bharathkumardev1/readmission-capacity): which discharged patients a care team should call when it can call one in ten. On 101,766 public encounters split by patient, a LightGBM call list holds 25.0% of 30-day readmissions, against 20.6% for calling whoever had the most prior inpatient stays. The README spells out who it misses. CI downloads the data, retrains, and fails if the headline metrics move beyond a small tolerance.
- [Agentic-Research-Assistant](https://github.com/bharathkumardev1/Agentic-Research-Assistant): cited answers about research papers from a LangGraph loop that reviews its own answer. On QASPER the loop ties a single pass that stops at the first search's top 5 passages and loses to a single pass over 10 or 15 (test, judged correct: 58.7% against 68.0%; the loop averages 5.6 passages), so a wider first search is the better use of the budget. CI replays the recorded model calls with no API key and fails if any answer, citation or score comes out different.

The first two have demos that run in the browser at [bharathkumardev1.github.io](https://bharathkumardev1.github.io), next to my résumé.
